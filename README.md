
# 🖼️ Responsive Image Gallery

A responsive image gallery built using **HTML, CSS, and JavaScript** as part of my **CodeAlpha Internship (Task 1)**.

The project includes category filters, hover effects, a lightbox view, and next/previous image navigation. It helped me practice JavaScript DOM manipulation and improve my frontend development skills.

## ✨ Features

- 📱 Responsive design for different screen sizes
- 🖼️ Image gallery with multiple categories
- 🔍 Category filters:
  - All
  - Nature
  - City
  - Animals
- ✨ Hover effects and smooth image transitions
- 🔦 Lightbox to view images in a larger format
- ⬅️ Previous and next image navigation
- ❌ Close button for the lightbox
- ⌨️ Keyboard navigation support:
  - `Arrow Left` – Previous image
  - `Arrow Right` – Next image
  - `Escape` – Close lightbox
- 🖱️ Click outside the lightbox to close it

## 🛠️ Technologies Used

## 📸 How It Works

### 1. Category Filtering

Users can filter images based on categories such as Nature, City, and Animals. JavaScript is used to display the images according to the selected category.

### 2. Lightbox

When a user clicks on an image, it opens in a larger lightbox view. The lightbox provides navigation controls to move between images.

### 3. Keyboard Navigation

Users can navigate through images using the keyboard:

- Press the left arrow key to view the previous image.
- Press the right arrow key to view the next image.
- Press the Escape key to close the lightbox.
